Sistema de Visualização de Notas

Uma aplicação desenvolvida para auxiliar professores e estudantes na compreensão do desempenho acadêmico, transformando diferentes formatos de avaliação em uma visualização padronizada de 0 a 100.

🎯 Sobre o projeto

Em muitos sistemas acadêmicos, as notas podem ser apresentadas de diferentes formas: porcentagens, quantidade de questões corretas ou valores influenciados pelo peso de cada atividade.

Isso pode dificultar a compreensão do desempenho final.
